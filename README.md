Entry for **[The Printer Apology](https://make.fun/c/u-eager-stork-81-9647-the-printer-apology-60229153)** on make.fun — write the funniest one-line apology from a printer, 120 characters max. An AI judge picks the funnier line in head-to-head pairs.

## The line

> Sorry I ate your report. It was 47 pages of 'final_FINAL_v2' and frankly, I did us both a favour.

(97 characters.)

## How it works

`main.py` is pure Python stdlib. It writes the line above, deterministically, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no randomness, no other I/O.

```sh
python3 main.py
cat /output/entry.txt
```
